## 常见问题

**Navicat for MySQL 和 Navicat Premium 差在哪？**

Premium 是全家桶，除了 MySQL 还能连 PostgreSQL、Oracle、SQL Server 和 MongoDB，一个客户端全接。for MySQL 只管 MySQL 和 MariaDB。功能深度上两者接近，差别在支持的数据库种类。

**只用 MySQL，买标准版够吗？**

够。标准版缺的只有 ER 图和 BI，日常写 SQL、传数据、做备份都不受影响。

**非商业版能用来接私活吗？**

不能。非商业版限教育机构和非营利组织使用，需要提供资质证明，商业项目用它属于违反授权条款。

**永久授权是不是一直能升级到最新版？**

不是。永久授权保证软件不过期，大版本升级通常涉及维护期，具体规则下单前问清楚。

**多久能收到授权？**

商品页写明 1–2 个工作日，人工处理，授权信息发到下单时填的邮箱。急用就提前下单。
